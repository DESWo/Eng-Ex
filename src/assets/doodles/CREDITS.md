# Doodle credits and provenance

All decals here are human-made by named professional illustrators, released
CC0 1.0 (public domain), verified 2026-08-08. Nothing in this
directory is stock-marketplace or AI-generated content.

## Open Doodles - Pablo Stanley
`sitting-reading.svg`, `reading.svg`
Source: https://www.opendoodles.com (official S3 bucket downloads)
License: CC0 1.0. Site text: "Free for Commercial and Personal Use. No need
to credit, license, or anything." Files vendored because the bucket could
move; CC0 explicitly permits redistribution.
Local edits: ink recolored to `currentColor`, accent #FF5678 recolored to
`var(--accent)`, fixed width/height removed so CSS controls size.

## Doodle Icons - Khushmeen Sidhu
`bulb.svg`, `trophy.svg`, `rocket.svg`, `star.svg`
Source: https://khushmeen.com/icons.html (SVGs via the react-doodle-icons
mirror on GitHub, cross-checked against the author's set)
License: CC0. Author's text: "Free icons for commercial and personal use
under CC0 license - no attribution required."
Local edits: same recolor/size treatment as above.

## Vetted and rejected (for the record)
- Hero Patterns (Steve Schoger, CC BY 4.0): human-made and licensable, but
  precise geometric style clashes with this app's hand-drawn language.
- unDraw: license forbids redistribution of assets; incompatible with an
  open repo.
- Notioly: paid, all rights reserved.
- Storyset/Freepik: stock marketplace - banned by project policy.
